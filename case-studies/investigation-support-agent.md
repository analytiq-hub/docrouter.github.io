*This describes a **consulting engagement** for a mid-size property-and-casualty carrier. The carrier is not named. The agent was deployed in their claims environment; this page stays at the architecture level.*

## Overview

When a policyholder reports a loss—by phone, web, mobile app, email, or voice—first notice of loss (FNOL) captures what the customer knows at that moment. What an adjuster needs next is different: whether the loss is likely covered, which policy forms matter, and what evidence is still missing. That first pass used to be assembled by hand.

We architected an **Investigation Support agent** so the legwork runs after FNOL. Adjusters start from an organized, cited package instead of a blank screen. The agent recommends; it does not deny claims or auto-close them.
